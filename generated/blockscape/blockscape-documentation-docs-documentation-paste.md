# Paste a BS file

You can load a model instantly by pasting JSON into Blockscape.

1. Copy JSON for a model or series.
2. In the app, click **Append model(s)** and paste the JSON.
3. Validate in the editor if you need schema checks before saving.

This is the fastest way to review a proposed map from chat or an LLM without downloading files.
